# My React App

This project is a React application that showcases various components and their styles. It is structured to facilitate easy development and maintenance.

## Installation
To get started with this project, clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd my-react-app
npm install
```

## Usage
To run the application in development mode, use the following command:

```bash
npm start
```

This will start the development server and open the application in your default web browser.

## Components
- **Footer**: Renders the footer section of the application.
- **Hero**: Serves as the prominent introductory section.
- **Modal**: Displays content in a modal dialog.
- **Navbar**: Renders the navigation bar.
- **ProjectCard**: Displays individual project information.
- **ProjectsGrid**: Renders a grid layout of project cards.

## Global Styles
The `GlobalStyles.js` file contains styles that apply to the entire application, ensuring a consistent look and feel.
